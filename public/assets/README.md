# ByteSpace Web Assets Directory

This folder contains all sorted, organized, and semantically renamed visual assets for the **ByteSpace** web application.

---

## Folder Structure

```text
public/assets/
├── brand/          # Logos, icons, and social authentication buttons
├── partners/       # Partner/sponsor brand marks (Logoipsum gray logos)
├── categories/     # Course category card badges with neon icons
├── courses/        # Course preview thumbnails & 3D collage graphics
├── heroes/         # Hero section character cutouts & illustrations
├── avatars/        # User testimonial profile pictures & avatar stack
├── widgets/        # Floating UI cards, rating badges & category tags
├── decorations/    # Floating 3D geometric shapes & background glow arches
├── designs/        # Full Figma page mockups, section references & style guides
├── manifest.json   # Machine-readable JSON metadata mapping
├── index.js        # JavaScript / TypeScript module exports
└── README.md       # Documentation & mapping reference
```

## Usage in Code

### In HTML / JSX
```html
<!-- In HTML -->
<img src="/assets/brand/logo-bytespace-header.png" alt="ByteSpace Logo" />

<!-- In React / Next.js -->
<img src="/assets/heroes/hero-student-male-composite.png" alt="Student" />
```

### In JavaScript / TypeScript
```javascript
import { ASSETS } from '/assets/index.js';

console.log(ASSETS.BRAND_LOGO_HEADER); // "/assets/brand/logo-bytespace-header.png"
```
